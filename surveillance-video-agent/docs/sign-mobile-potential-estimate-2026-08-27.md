## 结论

放宽到手机拍摄后，60 条在统计上首次成为可能。三批手机/小规模人工样本共17条，6条任务可用，累计可用率35.3%。最新纠正排序批次为1/5，说明公开元数据无法可靠识别镜头切换速度和采访包装。

用户已冻结“小规模”为1至5名直接参与举牌者。第三组小规模查询已完成，并显著增加了新 URL。更新后的点估计约为78条，重新超过目标60；仍需5条小规模人工标签校验。

两组唯一候选仅重叠 80 个，合并后是 953 个已观测 URL；300 个 probe 无重复，仍有 653 个合并候选未 probe。

第三组 `sign_action_v1.qp.v1.2.0` 专门检索1至5人小规模举牌：45/45搜索成功、489个唯一候选、150个新probe、9个probe失败、13个新来源合格。三组联集为1411个URL，450个probe无重复，仍有961个联集候选未probe。

后续审计发现probe前排序仍误用surveillance-only评分，导致明确手机/shorts候选被压低。修复后，同样查询和150 probe的来源合格数由12提高到23。再加入“手机查询 provenance + 10至90秒时长”的横屏短视频组合证据后，同样150 probe来源合格提高到53。累计来源/资源池由47扩至98。

修复后的multi-query产生10个候选；数值人数规则排除了450人、25,000人等明确大规模样本。现有Batch Generator使用当前小规模向量复核后，5条进入下载、5条保留为`below_semantic_threshold`。进入下载的5条全部技术成功，等待人工标签。

该5条人工结果为1/5可用。累计17条中6条可用。按35.3%可用率，获得60条人工可用视频预计需要约170条技术成功候选；按约95%技术成功率，下载尝试预算约180。当前`sign_action_v1`容量60代表下载候选数，不是人工可用数，按当前精度只能期望约21条可用样本。

因此若业务目标是60条人工可用视频，必须把候选容量版本化提高到约180，并以外部人工累计`usable=60`作为停止条件；如果目标只是60条下载候选，则现有容量无需改变，但无法承诺其中60条都可用。

## 可检索 URL 宇宙

两组估计已由三样本 Chao2 更新。三组候选按出现次数分布为：只出现于1组的1303个、出现于2组的105个、出现于3组的3个。

```text
Sobs = 1411
Q1 = 1303
Q2 = 105
T = 3

Chao2 ≈ Sobs + ((T-1)/T) * Q1² / (2*Q2)
      ≈ 6801
```

Chao2同样受搜索引擎Top-20、查询相关性和异质捕获概率影响，因此6801只用于容量规划，不是候选事实数；它说明第三组带来了大量前两组未覆盖的搜索空间。

## 来源池估计

合并 450 个不重复 probe 后，累计31个候选满足以下条件（含已下载估计样本）：

- `camera_pool` 为 `surveillance` 或 `mobile_adjacent`；
- 来源分 `>=4`；
- 资源合格；
- 不在未释放的 suppression 中。

来源通过率点估计：

```text
31 / 450 = 6.89%
```

应用到6801个URL的来源池点估计约为468条。

## 语义池与人工精度

20 个来源候选中，7 个的 sign embedding 相似度 `>0.44`，语义候选率点估计 35%。7 条均已串行下载并通过技术验证。

最终人工可用量的点估计可简化为：

```text
约 217 个来源候选 * 35% 语义通过率 * 人工可用率
```

人工结果现已写入审计。等价估计如下：

| ---: | ---: |
| 0 | 0 |
| 1 | 11 |
| 2 | 22 |
| 3 | 32 |
| 4 | 43 |

前两组手机 Pilot 实际为3/7可用。三组来源候选中，旧手机语义候选7条与新小规模语义候选5条合计12条，占31个来源候选的38.7%。更新后的点估计：

```text
6801 * (31/450) * (12/31) * (3/7) ≈ 78 条
```

因此60条在点估计上可达。新5条小规模样本已5/5技术成功，等待人工任务标签。若其中至少2条可用，合并人工精度仍足以支持继续扩量；若0–1条可用，需要再次下调潜在量并停止或更换平台。

本轮 `source_correct` 不纳入统计：界面仍使用“固定监控”问题，而该 Campaign 已允许 `mobile_adjacent`。界面已修复，后续手机池会询问“是否真实手机/短视频拍摄且非影视、游戏、教程或广告”。

一条人工备注提出希望“小规模”举牌。该条件会改变任务定义，必须由用户在主对话显式确认后才能冻结；当前报告不把附件备注自动转成规则。
